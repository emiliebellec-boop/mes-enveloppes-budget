# Mes Enveloppes Budget

Application personnelle de budget par enveloppes, conçue pour fonctionner sur iPhone comme une PWA.

Fonctions de la V1 :
- revenus saisis manuellement ;
- charges fixes récurrentes ;
- enveloppes personnalisées ;
- budget mensuel ;
- report positif ou négatif ;
- suivi global au choix par trimestre civil ou par année ;
- épargne avec objectif ;
- export/import d'une sauvegarde JSON ;
- stockage local sur l'appareil, sans connexion bancaire.

Les données personnelles ne sont pas enregistrées dans GitHub : elles restent dans le stockage local du navigateur.
